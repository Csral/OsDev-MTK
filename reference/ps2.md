# PS 2 keyboard
PS/2 keyboard talks to PS/2 controller and app. was common on old PCs before USB was common, it had some ports for mouse and keyboards.
We parse "scan codes" to get the KEY that was pressed!!

Apart from this toy variant, review OSDev to implement a better driver.
